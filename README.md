# Book Inventory Management System
This full-stack web application allows users to log in or create an account to manage their personal or group reading lists. Users can search for books, add or remove them from lists, and leave reviews. The platform supports both individual and collaborative reading experiences through group reading lists.

## Project Overview
This project was developed as a team for our Database Management Systems course. We applied key principles from database theory and system design to build a functional, user-focused application.

## Features
- User Authentication (login & registration)

- Book Search Functionality

- Create and Manage Reading Lists

- Group Reading Lists for Shared Reading Goals

- Book Reviews and Ratings

- SQL-driven backend with secure data handling

## Technologies Used
- CSS
- PHP
- SQL

## Development Process
- Brainstorming & Planning – Collaborated to define core features and user flows

- Entity-Relationship Diagrams (ERDs) – Designed database schema and relationships

- Database Design – Created and populated relational database using MySQL

- SQL Query Writing – Developed complex queries for user and book interactions

- Backend Development – Implemented logic in PHP for dynamic functionality

- Frontend Design – Created responsive and intuitive UI using HTML/CSS

## Learnings & Takeaways
- Gained hands-on experience with relational database design and normalization

- Practiced collaborative development using Git and version control

- Applied security best practices for user authentication and data validation
